Keyboard Shortcuts
?
Enables keyboard shortcuts for various actions in iiQ.

Ctrl+K - Opens the global search bar
Alt+S - Issue or return a spare from the ticket detail page
Alt+A - Assigns the ticket to the user
Alt+R - Resolves the ticket (auto confirms issue)
Alt+C - Confirms the issue
Auto Close Sidebar
?
Automatically closes the sidebar navigation on page load.
Split View
?
Ctrl+Click a ticket or asset to display a split view of details.
